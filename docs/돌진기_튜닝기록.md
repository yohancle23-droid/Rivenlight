# 돌진기 튜닝 기록

기획서(전투 기획서 v2)를 보고 구현하면서, 직접 플레이해 보고 바꾼 값과 그 이유를 남기는 문서.
흐름: **기획 → 구현 → 플레이 테스트 → 조정**

---

## 확정한 값

| 항목 | 기획서 / 가이드북 | 현재 값 | 이유 |
|---|---|---|---|
| 발동 거리 `DashMinDistance` | 기획서 "접근·추격 7m~" / 가이드북 3m→12m(임시) | **700 (7m)** | 기획서 거리 구간(근거리 ~3m · 원거리 3~7m · 추격 7m~)을 따름. 7m에서 돌진하면 플레이어 앞 2m에서 멈춰 최소 5m 이동 → 기획서 돌진 범위 세로 5m와 일치. "적당히 타이트하게" 의도. 너무 압박이 심하면 10m로 늘릴 예정 |
| 쿨타임 `DashCooldown` | 가이드북 6초(임시), 기획서 없음 | **6초** | **기획서상 플레이어 대시 쿨타임(3초)의 2배.** (플레이어 대시 쿨타임은 아직 미구현, 기획서 기준) 플레이어가 돌진을 대시로 피한 뒤, 다음 돌진이 올 때는 항상 대시가 다시 준비돼 있음 → 돌진마다 회피 수단 보장 |
| 속도 곡선 | 가이드북 Alpha²(= Ease In 2) | **Ease In, Blend Exp 3** | 가속감을 더 강하게. Expo In은 끝 0.1초에 이동이 몰려 순간이동처럼 보여 폐기 |
| 멈춤 거리 (UpdateEndLoc 곱하기 노드) | 가이드북 200(임시) | **100 (1m)** | attack03은 앞으로 찌르지 않고 양옆으로 펼치는 베기라 앞쪽 사거리가 짧음. 200에서는 가만히 서 있어도 도끼가 플레이어 앞 허공을 가름 → 100으로 줄이자 대부분 적중 (가끔 빗나감, 관찰 중) |
| 판정 반지름 `TraceRadius` (AC_MeleeTrace) | 45 | **68 (1.5배)** | 판정이 도끼의 두 점(Top·Bottom)만 쓸고 지나가서, 보스 몸 옆에 붙은 플레이어는 두 궤적 사이에 들어가 안 맞음. 일반 공격에도 같이 적용됨 |
| 보스 회전 속도 (Character Movement Rotation Rate Yaw) | 없음 | **280°/s** | Rotate 무한 대기 수정 후 회전이 휙 돌아 어색함 → 낮춤. 발이 안 움직이는 회전이라 완전히 자연스럽진 않지만 **이 정도에서 마무리 (더 다듬으면 끝이 없음, 제자리 회전 애니는 동결 후 목록)** |
| 돌진 종료 시각 `DashEndTime` | 가이드북 1.3초(도착 즉시 종료) / 기획서 FINISH 2.0 | **2.0초** | 1.3초에 끝나면 BT가 바로 Move To로 넘어가 회수 몽타주(2.85초까지) 중에 미끄러짐 → 2.0초까지 제자리에서 회수 후 Stop Anim Montage로 끄고 종료. 이 0.7초는 **미끄러짐 방지용 회수 동작일 뿐 반격 틈이 아님** (대시로 피하면 이미 몇 m 떨어져 있고, 다시 붙는 시간 + 플레이어 공격 선딜 > 0.7초). 반격은 기획서의 **극한 회피 → 그림자 밟기**(거리가 멀어졌을 때 쓰는 연계 공격)가 담당. 후딜을 길게 주면 그 보상을 공짜로 주는 셈이라 0.7초 유지 |
| 보스 시야 | 기본값 | 시각 30m / 상실 35m / 반각 180° | 멀어지면 추적이 끊겨 먼 거리 돌진을 쓸 수 없었음 |

## 회피 설계 (Blend Exp 3 기준)

- 0~0.5초: 준비 자세 (기획서 READY + MOTION1)
- 0.5~1.0초: 가속 돌진 + 플레이어 추적. 1.0초 시점에 전체 거리의 약 24%만 이동
- **1.0초: 방향 고정** → 남은 76%를 0.3초에 몰아서 이동
- 1.3초: 도착 · 충돌 판정 (기획서 Impact)
- **회피 창: 1.0~1.3초 (0.3초).** 1.0초 전에 피하면 추적이 따라옴

## 보류 / 나중에 조정할 것

- **최대 돌진 거리 10m (`DashMaxDistance`)**: 지금은 거리 제한 없음(플레이어 앞 2m까지). 공격까지 붙여서 못 피하겠으면 넣음
- 회피가 너무 어려우면 시도 순서: `FreezeTime` 1.0 → 0.9 (회피 창 0.4초) → Blend Exp 2 → 최대 거리 10m
- Part 2 스킬 선택표의 돌진 조건(가이드북 1200)도 700으로 맞추기

## 구현 중 발견한 문제

- **돌진이 조금 가다 멈추고 걸어옴**: 도착점 높이가 플레이어 몸 중심이라 경로가 아래로 기울어 Sweep이 바닥에 걸림 → 도착점 Z를 출발점 Z로 고정 (Break/Make Vector)
- **보스가 옆으로 움직임**: Lerp A(출발점) 선이 빠져 맵 원점(0,0,0)에서 출발 → Start Loc 재연결
- **카펫을 건너는 돌진만 짧게 끝남**: Sweep 이동 + 높이 고정이라 바닥보다 살짝 높은 Arena_Carpet 모서리에 보스 캡슐이 걸려 멈춤 → 카펫 콜리전 NoCollision. 아레나 바닥 장식을 바꿀 때도 같은 문제 주의
- **보스가 가끔 멈추고 아무것도 안 함 (진짜 원인)**: BT의 Rotate to face BB entry가 "Current angle 150°"에서 영원히 대기. 이 노드는 포커스만 주고 회전은 캐릭터 무브먼트에 맡기는데, 보스가 Orient Rotation to Movement(이동 방향으로만 회전)라 제자리에선 안 돎. 돌진 뒤 옆·뒤를 보고 멈추면 Move To는 바로 끝나고 Rotate에서 갇힘 → Orient Rotation to Movement 끔, Use Controller Desired Rotation 켬, Rotation Rate Yaw 설정. 찾은 방법: PIE 중 BT 디버거로 멈춘 노드와 노드 안 디버그 값 확인
- **걷는 도중엔 멀어져도 재돌진 안 함**: Part 1 구조상 정상(거리 체크는 돌진 차례에 한 번). Part 2 스킬 선택 구조에서 해결

## 기획서 수정 메모

- 스킬 용도: "거리를 벌린 플레이어에게 빠르게 따라붙는 압박 패턴. 전조 자세(0.5초)와 방향 고정(1.0초)을 보고 반응하면 회피 가능"
- 발동 조건 추가: 거리 7m 이상 + 재사용 대기 6초
- 패턴 설명: 0.5초 준비 후 0.8초 가속 돌진, 도착 직전 평균 3배 속도. 1.0초까지 추적 후 방향 고정
- 파훼: 방향 고정(1.0초) ~ 충돌(1.3초) 사이에 옆으로 대시

## 테스트 기록

### 5단계 발동 조건 (거리 7m + 쿨타임 6초)
- **거리**: 돌진 차례마다 거리를 Print String으로 출력 → 돌진 5회 모두 13~29m(7m 이상)에서만 발동 ✅
- **쿨타임**: 6초는 사이클(걷기 + 공격 + 2초 대기)에 묻혀 체감이 어려움 → **DashCooldown을 30초로 늘려 검증**
  - 공격을 맞은 뒤 10m 이상 거리 벌림 → 돌진 차례였지만 쿨타임 중이라 걸어옴
  - 30초 동안 거리 유지 → 30초 지나자 다시 돌진 ✅
  - 검증 후 6초로 복구
- 배운 점: Part 1 구조(돌진 → 걷기 → 공격 → 대기)에서는 거리 체크가 돌진 차례에만 일어나서, 쿨타임이 사이클 길이보다 짧으면 효과가 거의 안 보임. 쿨타임이 실제로 의미를 갖는 건 매 사이클 스킬을 고르는 Part 2 구조

### 6단계 돌진 베기 판정 (ANS_TraceWindow L·R, 21~26프레임)
- 테스트 1(가만히 서서 받기), 멈춤 거리 200: 안 맞음 (사용자가 먼저 "안 닿는다"고 지적)
- 같은 테스트, 멈춤 거리 100: 대부분 맞음, 가끔 빗나감 → 원인 관찰 중 (보스가 향한 각도 추정)
- 영상: 20261020_Rivenlight_돌진기_6단계_판정테스트1_멈춤거리200_실패 / _멈춤거리100
- 남은 테스트: 2-A 일찍 피하기(맞아야 함), 2-B 1.0초 급가속 순간 피하기(안 맞아야 함), 3 다 펼친 뒤 다가가기(안 맞아야 함). slomo 0.3 사용
- 판정 반지름 68 + 카펫 콜리전 끈 뒤 테스트 1(가만히 3번): **3/3 피격** ✅
- 테스트 2-A(일찍 옆으로 달려 피하기): FreezeTime 1.0 맞음 / **0.5 안 맞음** → 추적 작동 확인 (A/B, 바꾼 값 하나). 도끼 폭이 넓어 1.0 결과만으로는 구분 불가였음. 복구 1.0
- 회피 계산 (Max Walk Speed 600, Max Acceleration 1500): 1.0초에 출발하면 0.3초에 0.67m → 달리기로는 못 피함. 미리 달리던 중 옆 1.8m < 도끼 폭 약 2.7m(추정) → 못 피함, 뒤로는 약 2.8m 거리 → 피함. 대시로 피하는 패턴 → 2-B 테스트로 검증 중
- 테스트 2-B 뒤(미리 보스 반대 방향으로 달리기): **안 맞음** ✅ (판정 구체가 등 뒤에서 펼쳐졌지만 몸에 닿지 않음 → 계산과 일치). 테스트 중 맵이 좁아 뒤로 빠질 공간이 부족했음
- 테스트 2-B 대시(③ 튀어나오는 순간 옆으로 대시): 1/1 회피 ✅ (HP 그대로). 테스트 3은 아래
- 테스트 2-B 옆 달리기(③에서 대시 없이 옆으로 달리기): 3/3 맞음 ✅ (예상대로. 달리기만으로는 회피 창 안에 도끼 폭을 못 벗어남 → 대시가 필요한 패턴)
- 테스트 3 판정 잔류(뒤로 빠진 뒤 다 펼친 도끼에 몸 대기): 판정 구체 사라짐, 안 맞음 ✅ → 26프레임 이후 판정 꺼짐 확인. 대시는 거리가 멀어 이 테스트에 못 씀
