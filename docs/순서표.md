# 순서표

작업은 30분~1시간 단위로 쪼갠다. 한 번에 하나: 기록 → 만들기 → 검사 OK → 내 파일만 커밋 → 기록.

## AI 역할 분담 (이 프로젝트에서 실제로 쓰는 것)
| 누가 | 맡는 일 | 하지 않는 일 |
|---|---|---|
| 사용자 | 방향, 재미, 수치 결정. 에디터 조작. PIE로 직접 플레이하고 판단 | — |
| 개발 세션 (Claude Code) | 안내, 코드·스크립트·표 작성, 값 읽기 | 결정 뒤집기, 허락 없는 쓰기 호출 |
| 기록 담당 (같은 세션이 작업 끝에) | 결정사항·작업기록·순서표 갱신, 선택→이유 정리 | 코드·표 수정 |
| 검수 (별도 세션 또는 `/code-review`) | 작성된 코드 검수 후 지적 | 코드 직접 수정 |

AI끼리는 서로의 대화를 볼 수 없다. 그래서 결정·할 일·진행은 `결정사항.md`, `작업기록.md`, 이 파일에 남겨서 이어 일한다.
