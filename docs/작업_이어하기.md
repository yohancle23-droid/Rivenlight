- 행동: 레퍼런스(P의 거짓 차징)를 요소로 분해 → ① 몸 주변 불씨 = 작은 스프라이트 다수 ② 가로 섬광 = 동그란 빛 하나를 가로로 늘린 것(1000×12). 처음 다뤄 보는 UE5.8 나이아가라로, 이미 있는 머티리얼(MI_ember_Additive_Inst, M_Spark)만 써서 약 40분 만에 제작. AI는 단계 안내, 레퍼런스 분해와 색·타이밍 결정은 직접
- 기획 연결: 섬광 = 회피 신호. 돌진 0.48초 전 노려봄 구간 끝(0.3초)에 번쩍 → 플레이어가 대시 타이밍을 읽음. 색은 콘셉트에 맞춰 붉은색 → 금빛
- 검증: 처음엔 슬로에서만 잘 보임 → "면접관은 보통 속도로 한 번 본다"는 기준으로 크기·밝기·노출 시간을 키움
- 주의: "초보" 같은 표현 쓰지 않기. "처음 다뤄 본 도구를 레퍼런스 분해로 빠르게 익혔다"로 쓰기
- **자소서용 '결과와 기여' (조금 길게, 초안 10/20)**:
  - 결과: 전투 기획서의 돌진기를 UE5.8 블루프린트로 구현해, "0.5초 전조 → 1.0초 방향 고정 → 1.3초 충돌"의 0.3초 회피 창을 가진 패턴으로 완성했습니다. 추적을 끄고 켠 A/B 테스트와 회피 거리 계산으로 "일찍 피하면 따라오고, 방향이 고정된 뒤 옆으로 대시하면 피한다"는 의도가 실제로 작동함을 확인했습니다. 여기에 「P의 거짓」 '이름 없는 인형'을 레퍼런스로 직접 만든 전조 섬광, 타격 FX, 카메라 셰이크, 피격 모션을 더해 "온다 → 피해라 → 맞았다"가 화면에서 구분되게 했습니다.
  - 기여: 발동 거리 7m, 쿨타임 6초(플레이어 대시의 2배), 판정 반지름 45→68 같은 수치를 기획서와 플레이 테스트를 근거로 직접 정했습니다. 보스가 가끔 멈추는 버그는 추측으로 넘기지 않고 BT 디버거로 회전 노드의 무한 대기를 찾아 고쳤고, 6초 쿨타임처럼 체감이 어려운 값은 30초로 늘려 검증한 뒤 되돌렸습니다. AI는 구현 안내에 쓰되, AI가 틀린 해석과 수치는 기획서와 테스트로 바로잡고 그 과정을 회고 문서로 남겼습니다.
- **자소서용 '검증' — AI와 함께 (초안 10/20)**: 검증은 AI와 역할을 나눠 진행했습니다. AI에게는 테스트 절차와 회피 거리 계산 같은 초안을 맡기고, 저는 그 절차가 실제 플레이 흐름에 맞는지 고치고 결과를 직접 판정했습니다. 예를 들어 AI가 제안한 쿨타임 테스트는 공격까지 도달하지 않는 절차여서 "돌진 맞고, 공격 맞고, 10m 이상 벌리기"로 바로잡았고, 6초가 체감되지 않아 30초로 늘려 검증한 뒤 되돌렸습니다. 판정은 AI가 "플레이어가 움직여서"라고 넘긴 것을 가만히 서서 다시 테스트해 원인(멈춤 거리와 짧은 앞쪽 사거리)을 찾았고, 추적은 방향 고정 시각만 바꾼 A/B 테스트로 확인했습니다. 회피는 AI와 함께 계산한 "달려서는 못 피하고 옆 대시로만 피한다"는 예측을 실제 플레이 결과와 대조했습니다.
  - 추가하면 좋을 검증(내일, 영상용): 옆 대시 회피 1/1 → 5회 이상 반복 / 테스트 3(다 펼친 뒤 다가가기) / 차징 섬광을 보고 대시했을 때 회피 성공률
- **자소서용 한 줄 (사용자 요청, 최종 후보)**: 처음 다루는 UE5.8 나이아가라로, AI의 단계별 안내를 받아 보스 돌진의 전조 FX를 직접 만들었습니다.
- **자소서용 두 줄 (사용자 요청, 최종 후보)**: 「P의 거짓」 보스 '이름 없는 인형'의 섬광 FX를 레퍼런스로 삼아, 처음 다루는 UE5.8 나이아가라로 원하는 전조 모션을 직접 만들었습니다. AI의 단계별 안내를 받으며 불씨와 가로 섬광을 구성하고, 색과 타이밍은 제가 정해 플레이어가 피할 순간을 읽을 수 있게 했습니다.
- **자소서용 짧은 문단 — FX 전체 (초안)**: 보스 전투의 FX는 '보기 좋게'보다 '플레이어가 읽을 수 있게'를 기준으로 설계했습니다. 돌진 직전에는 회피 타이밍을 알리는 금빛 섬광, 돌진 중에는 경로를 보여 주는 몸의 궤적, 공격이 닿는 순간에는 타격 FX와 카메라 셰이크, 피격 모션을 넣어 "온다 → 피해라 → 맞았다"가 화면에서 구분되게 했습니다. 판매자 에셋은 레퍼런스 기준(얇고, 짧고, 날카롭게)에 맞는 것만 골라 고쳐 쓰고, 맞는 것이 없으면 AI의 단계별 안내를 받아 나이아가라와 캐스케이드로 직접 만들었습니다. 슬로 모션에서만 보이던 FX는 "보통 속도로 한 번 봐도 보이는가"를 기준으로 다시 조정했습니다.
- **자소서용 짧은 문단 (초안)**: 보스 돌진기의 전조가 플레이어에게 잘 읽히지 않는 문제가 있었습니다. 보유 이펙트는 콘셉트와 맞지 않아, 레퍼런스를 '몸 주변 불씨'와 '몸을 가로지르는 얇은 섬광' 두 요소로 분해하고 기준을 "얇고, 짧고, 날카롭게"로 정했습니다. 처음 다루는 UE5.8 나이아가라는 AI에게 단계별 안내를 받아 익히고, 색과 타이밍, 크기는 직접 정했습니다. 그 결과 약 40분 만에 돌진 0.4초 전 번쩍이는 회피 신호를 완성했습니다. 기준은 "면접관이 보통 속도로 한 번 봐도 보이는가"였습니다.
