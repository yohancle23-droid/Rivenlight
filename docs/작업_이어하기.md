1. **보스 돌진기(Part 1)를 다 끝낸 다음에** → 플레이어 대시 쿨타임 3초 구현 (B안)
   - BP_ThirdPersonCharacter: 변수 `PlayerDashCooldown`(3.0), `LastPlayerDashTime`(-999)
   - 대시 입력 → Branch((Game Time − LastPlayerDashTime) ≥ PlayerDashCooldown) → True: 기존 대시 → Set LastPlayerDashTime
   - 끝나면 자소서 문장을 "기획서 기준 설계" → "양쪽 구현"으로 수정
2. 그다음 **Part 3 갑옷 파괴 먼저** (기획 의도 ①② 직접 증명, 무조건 포함)
