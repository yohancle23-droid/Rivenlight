### 코드로 처리 vs 블루프린트로 처리 (D-09 기준)
| 방식 | 대상 | 표 |
|---|---|---|
| 코드가 자동 적용 (블루프린트 안 건드림) | 걷기 속도, 회전, 시야, 체력(`MaxHP`·`HP`), `GroggyPerDamage`, 플레이어 카메라 시야각·붐 길이, 플레이어 `HP` | `DT_MonsterList`, `DT_MonsterStatus`, `DT_Character` |
| 블루프린트에서 노드 교체 (`Get Tuning` 등) | 노드 안에 숫자가 직접 들어 있는 값: 히트스톱, 슬로모션, FOV 펀치, 셰이크, 입력 잠금, 넉백, 돌진기 값, 갑옷 파괴 배수, 대시 등 | `DT_Tuning`, 일부 `DT_Character` |

## 열린 결정
- 지인 피드백 후 걷기 다시 손볼지 (다리 클립 교체, 카이메라 리타게팅 포함)
- 엑셀을 열어 둔 채 튜닝하는지 (열려 있으면 자동 갱신이 파일을 덮어쓰지 못함)
- 실행 파일(패키징 빌드) 배포 여부: 유료 에셋 라이선스 확인 필요 [모름]
