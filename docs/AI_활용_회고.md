# AI 활용 회고: AI가 틀린 곳과 내가 잡은 방법

가이드북(AI가 기획서를 보고 만든 구현 문서)을 따라 구현하면서 발견한 AI의 약점과 대응을 남긴다.
자소서("AI를 활용해 문제를 해결한 경험")와 면접 자료. 원칙: **AI 결과는 기획서와 플레이 테스트로 검증한 뒤 쓴다.**

---

## 1. 큰 실수: 기획서를 수십 번 보여줬는데 돌진기를 다르게 해석함

- 기획서 21쪽: 돌진기 Impact = **"X자로 교차한 두 팔을 펼치며 공격"** → 돌진하면서 도끼로 베는 기술
- 가이드북 6단계: "돌진은 무기를 휘두르는 동작이 아니라 **몸통 충돌에 가까워서**" → 도착 순간 구(Sphere Overlap) 판정 하나로 처리
- 문제: 기술의 정체성(돌진 + 베기)이 사라짐. 구현은 쉬워지지만 기획 의도와 다른 기술이 됨
- 어떻게 잡았나: 구현 직전에 기획서 장면 설명과 가이드북 판정 방식을 비교 → 다름을 발견
- 대응: 기존 무기 판정(ANS_TraceWindow)을 쓰는 돌진 베기 몽타주(attack03)로 변경 (A-1안)
- 교훈: AI는 "구현하기 쉬운 쪽"으로 기획을 바꿔 해석할 수 있다. **기획서가 가이드북보다 우선**

## 2. 맥락 파악 부족: 수치와 구조가 기획서와 따로 놂

| 항목 | 기획서 | 가이드북 | 결과 |
|---|---|---|---|
| 돌진 발동 거리 | 추격 구간 7m~ | 3m(테스트) → 12m | 기획서 7m로 수정 |
| BT 구조 | 거리가 기술을 고름, 콤보로 연속 압박 | 돌진→걷기→공격→대기 2초 고정 순서 | "공격 후 대시"라는 기획에 없는 흐름이 생겨 긴장감 없음 → PickSkill 앞당기기 검토 |
| 후딜 | **일부** 콤보 뒤에만 | 모든 스킬 뒤 1.5초 일괄 | 기술별 차등으로 바꿀 예정 |
| 쿨타임 6초 | 근거 없음 | 임시 값, 이유 없음 | 플레이어 대시 3초의 2배로 근거를 직접 만듦 |

- 공통점: 숫자와 순서를 "일단 돌아가게" 정했고, 기획서의 의도(왜 이 거리인지, 왜 압박하는지)와 연결하지 않음

## 3. 쉬운 걸 어렵게 함 / 일을 길게 벌림

- 작업을 필요 이상으로 크게 잡고 길게 진행하려는 경향 → 사용량 한도가 빨리 소진됨
- 설명이 길고 단계가 많아 지금 무엇을 해야 하는지 흐려짐
- 대응: "행동 3개 이하, 확인 기준, 한 줄 PIE 확인"으로 답변 형식을 고정. 작업마다 시간 제한(예: 6단계 2시간, FX 찾기 10분)

## 4. 이번 세션 Claude가 한 실수 (같은 기준으로 기록)

- 구조체 핀 분할 설명이 헷갈려서 진행이 막힘 → Break/Make Vector 방식으로 바꿔 설명
- 쿨타임 테스트 절차를 잘못 제시(계속 멀리 있으면 공격까지 도달 안 함) → 사용자가 "돌진 맞고, 공격 맞고, 10m 이상 벌리기"로 바로잡음
- 기획서 7m 대신 15m를 먼저 제안 → 사용자가 기획서 근거로 바로잡음
- 사용자가 "가만히 있어도 안 닿는다"고 했는데 "플레이어가 움직여서 그렇다"고 넘김 → 판정 테스트에서 실제로 안 맞음. 원인은 멈춤 거리 200과 양옆으로 펼치는 베기의 짧은 앞쪽 사거리. 사용자의 플레이 감각이 맞았음
- 판정 시작을 판매자 Trail 노티파이 위치(18프레임)로 잡음 → 사용자가 프리뷰로 "아직 팔이 닫혀 있다"고 지적, 21프레임으로 수정
- 보스 멈춤을 처음엔 "슬로 모션에서 Wait 2초가 길어 보인 것"이라고 단정 → 사용자가 보통 속도에서도 멈추는 걸 보여줌. BT 디버거로 보니 Rotate to face BB entry가 150°에서 무한 대기(무브먼트 설정과 BT 노드가 안 맞음). 추정으로 닫지 말고 디버거로 확인했어야 함
- 자소서 MCP 문장을 "반복 작업 자동화"로 제안 → 레벨 디자인을 낮추는 표현이라 "전문 분야가 아닌 영역"으로 수정

## 정리: AI를 쓰는 내 방식

1. 구현 전에 **기획서와 AI 결과를 대조** (특히 기술의 정체성, 수치의 근거)
2. AI가 준 "임시 값"은 **근거를 직접 붙이거나** 플레이 테스트로 정함 (`돌진기_튜닝기록.md`)
3. 테스트 방법도 AI 제안을 그대로 쓰지 않고 실제 플레이 흐름에 맞게 고침
4. 답변 형식과 시간 제한을 정해 AI가 일을 키우지 못하게 함
